# 功能闭环补全

以原始方案、53 条需求与实际源码为依据。当前主流程可用，但缺少日常管理和恢复路径；本次在保留所有既有数据及 UI 改版的前提下完成：

1. 项目编辑、归档/恢复、负责人可访问的成员管理、成员移除与权限即时生效。
2. 任务编辑/重新分配/截止日期/授权/状态归档；防止旧页面覆写新修改；归档只读。
3. 服务端上传草稿恢复、说明自动保存、文件队列/进度/失败重试、未提交文件移除。
4. 真实 OBJ/GLB/GLTF/FBX 预览、相机控制、三维位置意见；图片预览保留，格式/依赖/解析错误明确回退。
5. 审阅完整性：版本切换不串评论草稿，历史定位、重复操作防护、评论编辑与审计。
6. 正式资产下架/恢复、手工标签编辑、授权限制调整；项目引用查看和移除。
7. 用户资料、安全、单条通知已读、通知分页与未读准确计数、收藏/交付/复用操作闭环。
8. 管理员用户资料/密码重置、模型配置参数及默认模型校验、完整日志分页筛选导出。
9. AI 会话：多轮上下文、持久化会话列表、重命名/归档、新建、失败可重试；其他五项 AI 能力保持可用。
10. 三端端到端验证、原功能回归、飞书 PRD/功能表增量同步、生产发布和数据备份。

视觉延续：canvas #F4F5F9，paper #FFFFFF，ink #242539，navy #24243D，violet #6955D8，soft #EEEBFC。沿用本地 Lato+CJK 字体。管理动作使用文本明确的工具条，草稿在交付区就地恢复，三维预览占审阅中央，不新增装饰性统计面板。

当前生产构建 .next-ui 保持服务；新构建独立目录 .next-complete，验证后切换服务环境变量，保留回滚能力。
